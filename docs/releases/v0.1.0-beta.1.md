# Ravel v0.1.0-beta.1

This is the first beta release of Ravel, an evidence-driven SBOM generator for local projects, package archives, installed systems, and saved container images.

## What is included

- CycloneDX 1.7, SPDX 2.3, and Ravel JSON output, plus a coverage report for unresolved claims and export losses.
- Package, dependency, and declared-origin evidence that can be inspected with `ravel explain`.
- Lockfile support across JavaScript, Python, .NET, Java, Rust, Go, Swift, Ruby, PHP, and additional ecosystems. See the [input matrix](../supported-inputs.md) for exact formats and versions.
- Local OCI layouts and Docker or OCI save archives, with installed-package and selected runtime detection.
- `diff`, `merge`, and explicit registry enrichment workflows.

## Beta limits

Results describe the scope of the input scanned. A declared registry URL is not proof of a download, and an installed package database may not establish a distribution origin or a complete dependency graph. Review the coverage report and [known limits](../limitations.md) before using a result as a completeness claim.

The release archives contain the CLI, README, LICENSE, NOTICE, third-party notices, and license files for compiled dependencies. Verify downloads against `SHA256SUMS`; see the [install guide](../install.md) for commands. Source builds require Go 1.27 or newer.

Bug reports and pull requests are welcome. Please include a minimal, redacted reproducer for parser or coverage issues; see [contributing](../../CONTRIBUTING.md).
