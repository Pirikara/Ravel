# Ravel v0.1.0-beta.2

This beta expands container and repository scans and adds installation options.

## Changes since v0.1.0-beta.1

- Scan a registry image by `image:tag` or digest, with an explicit platform when needed. Scan a local Docker daemon image with `--image-source docker`. The selected manifest digest is recorded in Ravel JSON.
- Record explicit repository runtime version selections and requirements from common Node, Python, Ruby, Go, Rust, .NET, Swift, Dart, and Flutter project files, with source evidence. These declarations do not establish the runtime installed in a deployment.
- Distribute a Linux amd64 and arm64 container image at `ghcr.io/pirikara/ravel:v0.1.0-beta.2`, built from the checksummed release archives. A Homebrew tap installs the native macOS and Linux binaries.

See the [install guide](../install.md), [CLI guide](../cli.md), and [known limits](../limitations.md). The container does not bundle package managers for opt-in dependency resolution.
