# Ravel v0.1.0

The first stable release of Ravel, a command-line SBOM generator that traces package, dependency, and source claims to their supporting input.

## Generate and inspect SBOMs

- Scan project lockfiles, local or remote Git repositories, package archives, installed systems, and container images.
- Export CycloneDX 1.7, SPDX 2.3, or native Ravel JSON with evidence, conditional relationships, coverage, and recorded package sources and development repositories.
- Collect installed language packages and runtime metadata alongside OS packages in images, including stripped Debian databases, Java runtime release files, and Composer PHAR metadata.
- Explain package records, explore a dependency graph offline, compare or merge native scans, and correlate externally issued OpenVEX statements.

See the [input matrix](https://github.com/Pirikara/Ravel/blob/v0.1.0/docs/supported-inputs.md) and [known limits](https://github.com/Pirikara/Ravel/blob/v0.1.0/docs/limitations.md) for exact formats and evidence boundaries. Metadata can establish declarations without proving an installed dependency graph or registry provenance. Rust executables need supported embedded audit metadata; opaque binaries such as the tested standalone uv image remain outside that detector's scope.

## Install or update

```sh
brew install pirikara/tap/ravel
```

Existing installations can use:

```sh
ravel update --channel stable
```

Checksummed binaries are attached for macOS and Linux on amd64/arm64 and Windows on amd64. The versioned Linux container is `ghcr.io/pirikara/ravel:v0.1.0` on amd64/arm64.

## Compatibility

The [compatibility policy](https://github.com/Pirikara/Ravel/blob/v0.1.0/docs/compatibility.md) defines CLI behavior, exit codes, native JSON schema changes, and update channels. Native JSON retains `schemaVersion: "0.1"`. Patch releases can correct detections and metadata while preserving the interface; preserve input digests, options, and the CLI version with your baselines.

Future beta releases remain available through versioned downloads and container images. The normal Homebrew formula follows stable releases.
