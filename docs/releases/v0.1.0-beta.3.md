# Ravel v0.1.0-beta.3

This beta adds correlation of externally issued VEX statements with Ravel scans.

## Changes since v0.1.0-beta.2

- Read a local OpenVEX v0.2.0 document with `ravel vex --input scan.ravel.json --vex supplier.openvex.json`.
- Match VEX products to scanned components by exact PURL, retaining all matching component IDs and explicitly reporting unmatched products.
- Show the issuer, vulnerability ID, status, rationale, timestamp, and SHA-256 digest of the VEX input in text or JSON output.

Ravel does not detect vulnerabilities, verify VEX signatures or issuer authority, or infer the application's status from a dependency statement. Subcomponent PURLs are displayed but are not correlated to the SBOM. See the [CLI guide](../cli.md#openvex-correlation) for matching details and the [install guide](../install.md) for binaries and package managers.
